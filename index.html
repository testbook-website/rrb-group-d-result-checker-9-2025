🔗 Connect Directly to Google Sheets (2 Minutes)

Paste your deployed Google Apps Script Web App URL below to automatically append every candidate check as a row in your Google Sheet:

Google Apps Script Code to Paste in your Sheet:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.timestamp || new Date(),
      data.name || "",
      data.mobile || "",
      data.rollNumber || "",
      data.zone || "",
      data.status || "",
      data.userAgent || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", message: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return doPost({postData: {contents: JSON.stringify(e.parameter)}});
}
  1. Create a new Google Sheet at sheets.new. Add headers in Row 1: Timestamp | Name | Mobile | Roll Number | Zone | Status | User Agent
  2. Click Extensions > Apps Script.
  3. Paste the code above and click Deploy > New deployment.
  4. Select type: Web app, Execute as: Me, Who has access: Anyone.
  5. Copy the Web App URL and paste it in the box above!
